**分析摘要**
抖音电商与 TikTok Shop 同源于字节跳动的内容推荐引擎，但在截然不同的市场环境中演化出各自独特的业务运作体系。抖音电商已成长为中国第二大电商平台（GMV 超 4 万亿元人民币），其核心竞争力在于"全域兴趣电商"模式——将内容推荐、搜索、直播和货架场景打通，形成从种草到成交的完整闭环。TikTok Shop则是一个覆盖 21 个国家和地区的全球社交电商平台（2025 年 GMV 约 335-643 亿美元），以"For You 推荐内容驱动 + 直播 + 货架商城"三场景融合为核心，正处于从高速扩张向成熟运营的转型期。

两平台的核心差异可归纳为五个维度：(1) 市场定位——抖音深耕单一成熟市场，TikTok Shop 进行多市场全球化布局；(2) 流量逻辑——抖音打通自然流量与付费流量边界（全域推广），TikTok Shop 以 For You 推荐为流量核心、货架场景加速崛起；(3) 商家生态——抖音约 460 万商家、低门槛入驻，TikTok Shop 约 150 万卖家、跨境与本土并行；(4) 物流履约——抖音依托中国成熟快递网络，TikTok Shop 需构建 FBT + 海外仓 + 跨境物流的复杂体系；(5) 监管合规——抖音受中国国内法规约束，TikTok Shop 面临美国禁令、欧盟 DSA、印尼本地化等多重监管挑战。
